# Inspection of Public TRELLIS Generation Samples

Date: 2026-10-17. Goal: find publicly downloadable 3D files generated by TRELLIS and check whether they already contain editable components/relations.

## Official Sources

- [TRELLIS project page](https://microsoft.github.io/TRELLIS/): 65 generation showcase items that explicitly link GLBs were extracted from the official `js/generation.js` (32 text-conditioned, 33 image-conditioned). The count applies to this version of the page and is not the total number of generated results on the web.
- [TRELLIS source code](https://github.com/microsoft/TRELLIS): the README states that the model weights and most of the code use MIT; dependencies have their own terms. The website's generated assets do not list individual licenses one by one, and the code license is not automatically interpreted as item-by-item permission for all samples.
- [TRELLIS.2 project page](https://microsoft.github.io/TRELLIS.2/): the showcase script contains 42 items, of which 16 declare GLB links; the page states that some lack GLBs because of website storage limits. This round confirmed that the first angel-statue GLB returns HTTP 200; the other 15 were neither downloaded nor verified one by one.
- [TRELLIS.2 source code](https://github.com/microsoft/TRELLIS.2), [online demo](https://huggingface.co/spaces/microsoft/TRELLIS.2).

## Findings for Component and Relation Research

All three GLBs have 2 nodes (`world`, `geometry_0`), 1 mesh, 1 mesh primitive, 1 material, and 1 texture; no skin, no animation. On Blender import there is likewise only one mesh object each, with no modifiers. There are no components named after books, shelf boards, chair legs, or cups, and no executable support/span/dimension dependency definitions were found.

A single mesh object does not mean all vertices are topologically connected; this round did not perform connected-component analysis, semantic segmentation, collision, or mechanics checks. Even if disconnected regions were split out, they cannot be treated directly as semantic components.

They can serve as input to "ready-made generated mesh -> semantic parts -> local interfaces -> assembly relations -> parameter-modification verification." It is recommended to start from the bookshelf, compared against the project's existing rebuildable bookshelf: the generated appearance is already usable, while the components and relations need to be recovered. The next step should first identify boards, books, and decoration, and then choose between fitting a parametric structure and keeping a rigid mesh; the whole model cannot simply be scaled to simulate a tier-height edit. This round did not perform segmentation or relation recovery.

## Data Not to Be Mistaken for a Library of Generated Results

- [TRELLIS-500K](https://huggingface.co/datasets/JeffreyXiang/TRELLIS-500K): the official card states explicitly that it is a collection of training assets filtered from Objaverse(XL), ABO, 3D-FUTURE, HSSD, and others, and is **not 500,000 models generated by TRELLIS**.
- [MeshFleet_TRELLIS](https://huggingface.co/datasets/DamianBoborzi/MeshFleet_TRELLIS): the card says it is the original MeshFleet models preprocessed with the TRELLIS training pipeline, and it cannot be used as proof of generated results.
- Many repositories with TRELLIS in the name in Hugging Face search are training data, code copies, latents, or large archives. None were classified as generated samples merely because of the shared name; what was actually downloaded this round is the official showcase results.

## Re-checkable Files

- `official_catalog.json`: 65 v1 generation items, prompt/input image names, full GLB URLs.
- `official_v2_catalog.json`: 42 v2 showcase items and whether each declares a GLB.
- `assets_manifest.json`: URL, actual byte count, SHA-256, and glTF structure of the three downloaded files.
- `models/*_gltf.json`: structure snapshots read directly from the GLB JSON chunk.
- `blender_audit.json`: mesh count, vertex/face count, bounds, and object names after Blender import.
- The project page, scripts, README, licenses, and Hugging Face API responses are saved in the same directory for source checking.

This result supports "publicly downloadable official generated samples exist," and does not mean that a large TRELLIS-generated dataset with full part annotations and assembly relations has been found.
