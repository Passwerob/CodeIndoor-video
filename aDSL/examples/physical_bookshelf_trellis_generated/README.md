# Installing a local TRELLIS mesh back onto the ADSL bookshelf

This example uses `E:\3DUse\research\trellis_generated_windows_20261017\trellis_component_raw.glb`, which was generated by inference on the local RTX 5060 Ti and then installed onto `book_19` as an independent `ExternalMesh`.

The main bookshelf, shelf boards and books are still generated by aDSL parametric code. The TRELLIS mesh only provides locally high-detail visual geometry; the installation position, local bounds and parent-child relations are kept in code.

```powershell
& E:\3DUse\aDSL\venv\Scripts\python.exe E:\3DUse\aDSL\scripts\local_3d.py build `
  --source E:\3DUse\aDSL\examples\physical_bookshelf_trellis_generated\model.py `
  --output E:\3DUse\aDSL\outputs\physical_bookshelf_trellis_generated_default --views 2
```

A change in tier height makes the bookshelf, the target book and the TRELLIS component re-solve their poses; the component is not implicitly stretched by structural parameters.
