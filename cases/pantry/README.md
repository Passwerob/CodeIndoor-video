# Pantry (tea room) — manual correction record v5.2

`runtime/` is not under version control, but the files here are **manually verified inputs** that cannot be regenerated by the pipeline, so they are stored separately.
Source: the `修正记录/` (correction records) folder and check results of the `CodeIndoor-Video_茶水间_手写建模_v5.2` (CodeIndoor-Video pantry, hand-modeled, v5.2) delivery package (2026-11-14).

| File | Type | Description |
|---|---|---|
| `measured/pose_overrides.json` | Manual input | Per-object, per-field pose/size corrections; each entry's `_why` states the evidence |
| `measured/extra_objects.json` | Manual input | Objects the automatic stage missed |
| `measured/room_features.json` | Manual input | Architectural elements that wall fitting cannot express |
| `measured/blend_overrides.json` | Manual input | Objects switched to the hand-written model in `runtime/outputs/hand/<id>/` |
| `geometry/camera_refine.json` | Recomputable (kept as baseline) | Per-frame camera correction from `geometry/refine_cameras.py` |
| `geometry/pose_refine.json` | Recomputable (kept as baseline) | Silhouette fine-tuning from `geometry/refine_poses.py`; `accept` means IoU improved by > 0.02 |
| `measured/clip_check.json` | Acceptance result | v5.2 origin/axis/static and motion interpenetration check (0 interpenetrations) |
| `measured/sim2real_audit.json` | Acceptance result | v5.2 sim2real audit (0 failures) |
| `CHANGELOG.txt` | Release notes | The delivery package's "Open Instructions" (《打开说明》), with the v5.1 → v5.2 changes |

Usage: put them into the run directory, then run `apply_measured.py`:

```bash
cp cases/pantry/measured/*.json runtime/video/pantry/measured/
cp cases/pantry/geometry/*.json runtime/video/pantry/geometry/
python geometry/apply_measured.py runtime/video/pantry
```

For the rules on editing these files, see `.claude/skills/scene-correction/SKILL.md`.
